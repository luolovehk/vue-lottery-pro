# Vue Lottery Pro - 3D抽奖系统

基于Vue.js开发的现代化3D抽奖系统，支持自定义奖项、3D球体展示、结果记录等功能，适用于各类活动抽奖场景。

## 项目介绍

Vue Lottery Pro是一个功能丰富、界面精美的抽奖系统，基于原`lottery-3d`项目进行了全面优化和增强。系统通过Three.js实现的3D球体展示抽奖参与者，提供了灵活的奖项配置和抽奖控制功能，同时支持抽奖结果记录和打印功能，为各类活动提供了专业的抽奖解决方案。

## 主要功能

### 核心特性
- **3D球体展示**：通过Three.js实现的3D球体旋转展示抽奖参与者
- **自定义奖项管理**：支持设置多个奖项、奖品名称、数量、每次抽取人数
- **灵活的抽奖控制**：可开始/停止抽奖，支持即兴加奖功能
- **中奖名单展示**：清晰展示各奖项的中奖者，支持滑动浏览
- **抽奖券打印**：支持批量打印抽奖券，可定制样式
- **背景音乐控制**：提供背景音乐播放功能，增强活动氛围
- **参与人数设置**：可灵活调整参与抽奖的人数
- **抽奖记录缓存**：使用localStorage和cookies保存抽奖进度，防止意外刷新丢失数据

### 视觉体验
- 现代化UI设计，支持大屏幕展示
- 喜庆的色彩搭配，适合各类活动场景
- 流畅的3D动画效果，提升用户体验
- 响应式设计，适配不同设备屏幕

## 技术栈

- **前端框架**：Vue.js 2.x
- **构建工具**：Vue CLI
- **编程语言**：TypeScript + JavaScript
- **3D渲染**：Three.js
- **状态管理**：Vuex
- **路由管理**：Vue Router
- **UI组件**：自定义组件 + Font Awesome
- **样式处理**：SCSS
- **本地存储**：localStorage、vue-cookies
- **动画效果**：CSS动画、自定义动画函数

## 安装与运行

### 环境要求
- Node.js >= 10.0.0
- npm/yarn

### 安装依赖

```bash
# 克隆项目
# 进入项目目录
cd vue-lottery-pro

# 安装依赖
npm install
# 或

yarn install
```

### 开发模式运行

```bash
npm run serve
# 或

yarn serve
```

浏览器访问：http://127.0.0.1:8080

### 构建生产版本

```bash
npm run build
# 或

yarn build
```

构建后的文件将生成在`dist`目录中。

## 使用说明

### 基本操作流程
1. **准备阶段**：配置奖项信息和参与人员名单
2. **选择奖项**：点击左侧奖项列表选择要抽取的奖项
3. **开始抽奖**：点击"开始抽奖"按钮，3D球体开始旋转
4. **停止抽奖**：点击"停止抽奖"按钮，系统随机选出中奖者
5. **查看结果**：中奖结果会显示在界面上，可滑动查看所有中奖名单

### 功能详解

#### 奖项配置
- 可设置多个奖项层级（特别奖、一等奖、二等奖等）
- 每个奖项可配置名称、奖品详情、总数量、每次抽取数量
- 支持按人员等级控制可参与的抽奖等级（V1.1.1版本更新）

#### 抽奖控制
- 支持暂停/继续抽奖
- 支持中奖作废重新抽奖功能
- 可设置单次抽奖的人数

#### 数据管理
- 系统会自动保存抽奖进度到本地存储
- 刷新页面后可恢复之前的抽奖状态
- 支持清除缓存重新开始抽奖

#### 扩展功能
- **打印抽奖券**：访问`/print`路径可进入抽奖券打印页面
- **背景音乐**：可控制背景音乐的播放与暂停
- **人数设置**：可灵活调整参与抽奖的人数上限

## 配置说明

### 奖项配置
在`src/views/lottery/lottery-config.js`文件中配置奖项信息：

```javascript
prizeList: [
  {
    count: 39,              // 奖项总数量
    countRemain: 39,        // 剩余数量
    everyTimeGet: 39,       // 每次抽取数量
    name: '特别奖·示例',    // 奖项名称
    detail: '徽章',         // 奖品详情
    id: '特别奖徽章',        // 奖项唯一标识
    level: 1,               // 奖项等级
    cardListWin: [],        // 中奖名单
    round: 0,               // 抽奖轮次
    isShowTime: false,      // 是否已展示
  },
  // 更多奖项...
]
```

### 参与人员配置
在`src/views/lottery/lottery-config-users-raw.json`文件中配置参与抽奖的人员名单。
